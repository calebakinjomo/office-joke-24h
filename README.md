# One-Line Office Joke: 24-Hour Sprint

Entry for the make.fun bounty
[u-pucuys-one-line-office-joke-24-hour-sprint-aaf86162](https://make.fun/c/u-pucuys-one-line-office-joke-24-hour-sprint-aaf86162)
("One-Line Office Joke: 24-Hour Sprint", free entry, $2 pot, top 10 split).

## The joke

> I muted myself to sigh, unmuted to say 'sounds good', and somehow that was my biggest contribution of the quarter.

## How it works

`main.py` prints exactly one line — the joke above — and nothing else.
`entry.txt` contains the same joke byte-for-byte. The entry is 114 characters,
well under the 200-character limit.

The line is about the meeting that should have been an email, told from a
fresher angle: the mute button as the only honest participant in the call,
and "sounds good" as a whole quarter's output.
